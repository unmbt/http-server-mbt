## 实现

- `internal/static_plan` 是 Native 与 Wasm 共用的静态决策状态机，负责表示选择、条件请求、Range、路由回退和目录渲染；不依赖 Native I/O 或 async Wasm 实现。根 Native 公共接口保持不变。
- `wasm` 导出真实 WasmGC 模块和版本化 JSON 控制桥接。文件元数据使用明确复制的字段，64 位偏移/长度使用十进制字符串，不经过 JS Number。正文文件字节由宿主按指定区间读取，默认块大小 64 KiB。
- [示例](../examples/wasm-node/README.md) 提供独立 ESM 文件宿主、类型声明、`createEngine`、`handle`、`close` 和 `node:http` 服务。应用无需 pump/poll，运行时不加载 `.node`。
- 请求和文件 ID 单调递增、不复用，耗尽拒绝接纳；操作序号拒绝重复/迟到完成。取消及关闭等待在途操作、文件关闭和正文 close 通知后返回。Readable 背压停止后续读取，并按预算限制连接、排队操作、正文和目录元数据。
- Wasm 宿主只承诺部署者控制的目录结构，拒绝 symlink/junction；恶意并发替换目录结构不在安全承诺内。文件内容更新仍支持检查与 `HS_FILE_CHANGED` 中止，不能当正常 EOF 或拼接重试。
